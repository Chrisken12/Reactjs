# Brightstart React app

A responsive React landing page built with React-Bootstrap and Bootstrap 5.

## Run locally

1. Install Node.js (npm is included).
2. Extract this folder and open it in VS Code or a terminal.
3. Run `npm install` to install the packages.
4. Run `npm start` and open the local address shown in the terminal.

The main page is in `src/App.js`; its custom styles are in `src/App.css`.
